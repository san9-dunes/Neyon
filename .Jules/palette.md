## 2026-04-23 - Add Tooltips to FloatingActionButtons\n**Learning:** FloatingActionButtons (and ImageButtons) in Android often have `contentDescription` set for screen readers but lack `tooltipText` for visual hover/long-press feedback, which degrades accessibility for pointer/mouse users or users relying on touch exploration.\n**Action:** Always verify that icon-only interactive elements in XML layouts define both `android:contentDescription` and `android:tooltipText` using the same localized string resource.\n
