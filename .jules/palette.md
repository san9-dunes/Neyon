## 2024-05-19 - Add tooltipText to FloatingActionButtons and ImageButtons
**Learning:** For accessibility and micro-UX in Android XML layouts, ensure icon-only interactive elements (e.g., ImageButton, FloatingActionButton) define both an accurate `android:contentDescription` for screen readers and `android:tooltipText` for visual hover/long-press feedback. For interactive elements with visible labels (e.g., `ExtendedFloatingActionButton`), provide `android:tooltipText` for visual hover support.
**Action:** When updating Android XML layouts with FloatingActionButtons, ExtendedFloatingActionButtons, or ImageButtons, explicitly define `android:tooltipText` matching the `android:contentDescription` or `android:text` string to improve accessibility for visual users during hover/long-press interactions.
