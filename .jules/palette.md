
## 2024-05-18 - ExtendedFloatingActionButton tooltips
**Learning:** `ExtendedFloatingActionButton` elements in this app often shrink to icon-only buttons on scroll, effectively losing their visible `android:text`. However, several core actions (like Continue Reading, Migrate, Add Directory) lacked `android:tooltipText`. Relying on the expanded text state is insufficient for a11y when the button can collapse. Furthermore, relying purely on `git patch` for complex Android XML changes in the sandbox is flaky due to unpredictable formatting drift; Python string replacement on the exact block provides a much more resilient editing strategy.
**Action:** Always add `android:tooltipText` matching the `android:text` to `ExtendedFloatingActionButton`s so users get a hint on hover/long-press when the button is in its shrunken state. When modifying complex, multi-attribute XML tags in the sandbox, use Python `content.replace(search, replace)` blocks instead of `replace_with_git_merge_diff` to avoid un-patchable failures.
